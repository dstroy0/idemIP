# Quotations tools/dev_env/rfc.py --audit cannot check, and why.
#
# The audit compares a quoted string against the RFCs the comment around it cites. Three kinds of
# quotation defeat that by construction, and every one of them is a correct quotation. They are listed
# here so the audit can reach zero and be a gate: an entry that stops matching a quotation in the tree
# is reported as stale, the same way tools/dev_env/counters.py reports a register that has drifted.
#
# One quotation per line, exactly as the comment writes it between its marks. A line starting with #
# is a comment and a blank line is nothing. Sections are named by a line of the form [name].

[procedure]
# RFC 791's numbered fragmentation and reassembly procedures, which are pseudocode set out one step per
# line with the step number in front. A comment quoting three steps writes them as a sentence with
# semicolons, and the document has them as a column.
# src/ip/ip4_frag.h
(7) Selectively copy the internet header (some options are not copied, see option definitions); (8) Append the remaining data; (9) Correct the header: IHL <- (((OIHL*4)-(length of options not copied))+3)/4; TL <- OTL - NFB*8 - (OIHL-IHL)*4); FO <- OFO + NFB; MF <- OMF; Recompute Checksum;
# src/ip/ip4_reass.c
IF FO = 0 AND MF = 0 THEN IF buffer with BUFID is allocated THEN flush all reassembly for this BUFID; Submit datagram to next step
# test/unit/ip/test_ip4_frag/test_ip4_frag.c

# test/unit/ip/test_ip4_frag/test_ip4_frag.c
(9) IHL <- (((OIHL*4)-(length of options not copied))+3)/4
# test/unit/ip/test_ip4_frag/test_ip4_frag.c
